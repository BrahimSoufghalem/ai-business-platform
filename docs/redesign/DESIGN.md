# وثيقة التصميم — «Operational clarity»

> هدوء بصري، كثافة معلومات مدروسة، وثقة تجارية. Light theme افتراضي.

## 1) الجمهور والمهمة

- **الجمهور**: أصحاب المتاجر والموظفون الذين يديرون المنتجات والمخزون والطلبات ورسائل Instagram والوكيل الذكي يوميًا.
- **المهمة الأساسية**: تشغيل متجر متعدد القنوات من مكان واحد — قرارات سريعة، لا استعراض بيانات تقنية.

## 2) Design Tokens

### الألوان (6 أساسية + دلالية)

| Token                                                                                     | القيمة                           | الاستخدام                                |
| ----------------------------------------------------------------------------------------- | -------------------------------- | ---------------------------------------- |
| `--bg`                                                                                    | `#f6f7f9`                        | خلفية الصفحة المحايدة (ليست بيضاء ساطعة) |
| `--surface`                                                                               | `#ffffff`                        | أسطح المحتوى والجداول                    |
| `--surface-2`                                                                             | `#eef1f5`                        | أسطح ثانوية/ممرّرة                       |
| `--text`                                                                                  | `#1c2534`                        | نص فحمي-كحلي                             |
| `--text-muted`                                                                            | `#5b6779`                        | نص ثانوي (contrast ≥ 4.5:1 على الأبيض)   |
| `--line`                                                                                  | `#d9dee6`                        | الحدود — قبل أي shadow                   |
| `--accent`                                                                                | `#1d4fd7`                        | أزرق كوبالت — إجراء رئيسي وروابط فقط     |
| `--accent-strong`                                                                         | `#173fa8`                        | hover/active للـaccent                   |
| `--success` `#157a3d` / `--warning` `#92580a` / `--danger` `#b3261e` / `--info` `#0b5bd3` | حالات فقط، مع خلفيات pale مطابقة |

### Typography

- **عربي**: IBM Plex Sans Arabic — **لاتيني/أرقام**: Inter — عبر `next/font/google`، عائلتان فقط.
- السلم: `12 / 13 / 14 (body-sm) / 15 (body) / 16 (forms) / 18 (h3) / 22 (h2) / 28 (h1 صفحة)`.
- الوزن: 400/500/600/700. لا letter-spacing على العربية، لا uppercase للعربية.
- الأرقام في الجداول: `font-variant-numeric: tabular-nums` (من Inter)، وليس monospace.

### Spacing / Radius / Elevation

- Spacing على شبكة 4px: `4 8 12 16 20 24 32 48`.
- Radius: `6` (حقول/أزرار)، `8` (بطاقات/جداول)، `12` (حوارات) — لا pills إلا للـbadges الحالة الصغيرة.
- الحدود أولًا؛ shadows فقط للقوائم المنسدلة والحوارات والعناصر العائمة (`--shadow-pop`).
- أهداف اللمس ≥ 44×44px؛ ارتفاع الحقول 40px (48px على الموبايل).

## 4) نقد ذاتي للخطة

- **هل تصلح لأي SaaS؟** لا — التنقل والمصطلحات (حالات الطلب، التحويل لموظف، Reorder point) مشتقة من نموذج بيانات هذا المنتج تحديدًا.
- **مظهر AI template؟** تجنبناه: لا gradients، لا بطاقات زجاجية، لا عناوين ضخمة، جداول حقيقية بدل بطاقات متطابقة.
- **بطاقات أكثر من اللازم؟** الجداول هي الافتراضي للمقارنة؛ البطاقات فقط لمؤشرات Dashboard المدمجة.
- **زخارف بلا وظيفة؟** حُذفت: لا أرقام 01/02/03، لا أسهم زخرفية، لا eyebrow caps، لا emoji كأيقونات.
- **ملاءمة تاجر يومي؟** كل صفحة تبدأ بسؤال تشغيلي: «ما الذي يحتاج تدخلي الآن؟» ثم إجراء مباشر.

## 5) اللغة والاتجاه

- ar (rtl) / fr / en — صفحة واحدة = لغة واحدة. الاستثناءات: اسم العلامة، Instagram، SKU/IDs، محتوى المستخدم.
- `Intl.DateTimeFormat/NumberFormat` بمنطقة المتجر الزمنية؛ CSS logical properties فقط؛ `dir="auto"` للنصوص الديناميكية.
